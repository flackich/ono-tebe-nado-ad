# Оно тебе надо

Учебная проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

## Технологии

HTML5, CSS, Grid, Flexbox. Шрифты и изображения хранятся локально. JavaScript и установка зависимостей не требуются.

## Просмотр

Откройте `index.html` в браузере. Страница рассчитана на ширину 1100 px согласно официальной заготовке проекта.

## Репозиторий

[Репозиторий проекта](https://github.com/flackich/ono-tebe-nado-ad)

## Ресурсы

Использованы изображения, логотипы, шрифты и базовые стили из [официальной заготовки Яндекс Практикума](https://github.com/yandex-praktikum/ono-tebe-nado-ad).
